## Featured Projects

### 1. 6-Tap FIR Filter ASIC – RTL to GDSII

**[View Repository](https://github.com/harshadjagtap17/6-Tap-FIR-Filter-ASIC--RTL-to-GDSII)**

Design and ASIC implementation of a 6-tap symmetric, multiplierless FIR low-pass filter for UAV flight command receivers.

- Developed a pipelined FIR architecture using Verilog RTL.
- Implemented symmetric coefficient-based pre-addition and shift-and-add arithmetic.
- Designed an 8-bit input and 13-bit output datapath.
- Performed functional verification using Xilinx Vivado.
- Executed synthesis and ASIC physical design using OpenLane 2 and SKY130A.
- Generated the final GDSII layout.

**Design Flow:**

`RTL → Verification → Synthesis → Floorplanning → Placement → Routing → DRC/LVS → GDSII`

**Technologies:** Verilog, Vivado, Yosys, OpenLane 2, OpenROAD, Magic, SKY130
