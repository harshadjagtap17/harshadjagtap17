## Projects

### 1. 6-Tap FIR Filter Accelerator – ASIC Implementation
A multiplierless, pipelined low-pass FIR filter designed for UAV flight command signal processing.

- Designed a 6-tap symmetric FIR architecture using Verilog.
- Implemented shift-and-add arithmetic with symmetric pre-addition and ripple-carry adders.
- 8-bit unsigned input and 13-bit unsigned output architecture.
- Functionally verified using Xilinx Vivado 2024.2.
- Implemented the ASIC physical design flow using OpenLane 2 and SKY130A.
- Generated the final GDSII layout.

**Implementation Flow:**

`RTL Design → Functional Verification → Synthesis → Floorplanning → Placement → Routing → DRC/LVS → GDSII`

**Tools:** Verilog, Vivado, Yosys, OpenLane 2, OpenROAD, Magic, SKY130

---

### 2. Four-Bit Round-Robin Arbiter
A synthesizable Verilog implementation of a four-requester round-robin arbitration architecture.

- Implemented a 2-bit priority pointer.
- Designed circular priority-based combinational grant logic.
- Ensured fair arbitration between competing requesters.
- Implemented priority-pointer updates following successful grants.

**Tools:** Verilog, RTL Design, Digital Logic Design
